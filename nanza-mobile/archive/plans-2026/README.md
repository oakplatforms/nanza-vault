# Local plans (scratch — gitignored)

Day-to-day implementation plans live here while you work. This folder is **gitignored**: nothing here is committed to the repo or synced to the Obsidian vault.

When a piece of work lands, don't keep the plan — **graduate its durable insight** into the matching feature **solution design** in the vault at `documentation/solution-designs/<theme>.md` (create it if it doesn't exist). The vault holds living overviews of how features work, not day-by-day change logs.
