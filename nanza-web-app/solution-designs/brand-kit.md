# Brand Kit — `/brand-kit`

**Status:** built 2026-10-24, uncommitted. Routed but **linked from nowhere** and `noindex` until it launches.

## What it is

A press/partner/creator page on the public marketing site: logo files, logo sting, logo slides, colors,
ready-to-paste one-liners and FAQs, with the logo usage rules inside the Logo section (under its zip
button), a "Download the full kit" zip, and a vertical, numbered jump list under the intro (numbers match the
section steps).

**Hero artwork:** `PageLayout` takes an optional `aside` (right half beside the headline, `lg`+,
out of flow so the headline doesn't move), filled per path from `PAGE_ASIDES` in `AppLayout.tsx` like
`PAGE_CLOSERS`. The brand kit's is `FloatingMark` — the mark large over a breathing pink glow, a 7s
float and a spring tilt toward the pointer (framer-motion; still under reduced motion). The mark path
is shared from `src/sections/brandMark.ts` with the nav logo.

**Same-page anchor scrolling is site-wide** (`src/hooks/useSmoothAnchors.ts`, called from `PageLayout`
and `GuidePage`, deliberately not the Lenis-driven landing): one capture-phase document click listener
animates any link to a section of the current page — plain `#` links, the legal contents lists, router
`<Link>`s to the same path — with GSAP ScrollToPlugin, `expo.out` (fast, no overshoot — `back.out` read as wobble),
duration 0.55s + distance-scaled, capped at 1.1s, `autoKill` on user scroll, plain jump under reduced
motion. Arriving from another page with a hash stays the instant jump in `usePublicSite`.

## How it works

- **Routing:** an entry in `src/pages/pages.ts` (`slug: 'brand-kit'`, not `primary`, `noindex`) plus
  `'/brand-kit': BrandKitCopy` in `PAGE_BODIES` (`src/app/AppLayout.tsx`). Standard `PageLayout`
  frame — dark theme, nav, footer — like `/support`. To launch: drop `noindex`, link it (footer is the
  natural home), add it to `public/sitemap.xml`.
- **Content as data:** `src/pages/brand-kit/kit.ts` lists every section, file, color, one-liner and
  FAQ; `BrandKitCopy.tsx` only lays it out. A `KitFile` with no `href` renders as a greyed "Soon"
  chip — that is how the logo sting is shown until it is cut.
- **Files:** `public/brand-assets/` (deliberately not `public/brand-kit/` — a static directory at the
  route's path makes the dev server redirect to a directory URL instead of the SPA).
  Generated by `scripts/build-brand-assets.py` from the master logo paths: SVG / transparent PNG /
  JPG for on-light, on-dark and mark-only; 4K logo slides 16:9 + 9:16, light + dark; three zips.
  Rendered with headless Chrome + Pillow — re-run the script rather than editing exports by hand.

## Logo rules (2026-10-24 artwork)

- Mark is solid **Nanza Pink `#ED3594`** on every background. (The master stacks a 100% and a 60%
  copy of the same pink; flattened to one fill in all exports.)
- Wordmark is `#010101` on light, `#FFFFFF` on dark.
- The marketing nav (`src/sections/Navigation.tsx` `Logo`) draws this artwork inline with the
  wordmark on `currentColor`; `public/nanza-logo-full.svg` (light screens) and `public/nanza-logo.svg`
  (mark) were replaced with it. The old `#FF4BFF` gradient mark still lives in `GradientMark`,
  the 3D scene, favicons and app icons — not yet updated.
